🔄 工作流程图

📝 工作流说明

1

请求接收与认证

接收用户请求，通过 JWT 或 OAuth2.0 进行身份验证与授权

2

Agent 选择与路由

根据需求选择最佳 Agent，支持智能路由与负载均衡

3

执行与监控

执行任务，记录分析指标，实时监控状态

4

结果返回

收集执行结果，整理后返回给调用方

⏱️ 时序图

📖 时序说明

步骤 1-3: 安全认证

客户端发送请求，安全模块验证 JWT 或 OAuth 令牌，认证通过后继续处理

步骤 4-6: Agent 选择

编排服务根据需求查询 Agent 注册表，选择最佳匹配的智能体

步骤 7-9: 任务执行

Agent 执行任务，处理完成后将结果返回给编排服务

步骤 10-11: 记录与响应

记录执行指标用于分析，最终将结果返回给客户端
